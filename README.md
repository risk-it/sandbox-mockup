# Measure Bank Sandbox Mock-up.
Design mock-up for configuring an alternative EMS response (AER) dashboard based on key measures that monitor the performance of AER programs.

This projoect is a collaboration between Arizona State University, George Mason University, and UC Irvine, supported by the U.S. National Science Foundation (NSF) under Grant No. 2211359, 2211360, and 2211361.
